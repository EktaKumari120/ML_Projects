# Titanic Exploratory Data Analysis

## Business Problem
Understand which passenger characteristics were most strongly associated 
with survival on the Titanic, using historical passenger records.

## Approach
- Cleaned and explored the Titanic dataset (handled missing values in Age, Cabin, Embarked)
- Analyzed survival rates across passenger class, gender, age groups, and family size
- Visualized relationships using bar charts, histograms, and correlation heatmaps
- Summarized key patterns driving survival likelihood

## Tools & Libraries
Python, Pandas, Matplotlib, Seaborn

## Key Insight
Passenger class and gender were the strongest visible factors in survival 
rate — first-class passengers and women had significantly higher survival 
rates than third-class passengers and men.
