# Sales Dashboard

## Business Problem
Businesses need an easy way to monitor revenue, units sold, and regional 
performance without manually digging through spreadsheets.

## Approach
- Generated a synthetic sales dataset using NumPy (dates, regions, products, revenue)
- Built an interactive Streamlit dashboard with filters for date range, region, and product
- Used Plotly for interactive charts (revenue trends, regional comparison, top products)

## Tools & Libraries
Python, Streamlit, Pandas, NumPy, Plotly

## Key Insight
An interactive dashboard lets non-technical stakeholders explore sales 
trends themselves, instead of requesting a new static report for every question.
