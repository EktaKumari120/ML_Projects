# Weather Dashboard

## Business Problem
Provide users with an easy, visual way to check current and forecasted 
weather conditions for any city, instead of reading raw API data.

## Approach
- Connected to the OpenWeatherMap API to fetch live weather and forecast data
- Built an interactive Streamlit dashboard to display temperature trends
- Used Plotly to visualize forecasted temperature changes over time
- Processed and structured API response data using Pandas

## Tools & Libraries
Python, Streamlit, Plotly, Pandas

## Key Insight
Wrapping a weather API in an interactive dashboard makes multi-day 
temperature trends far easier to interpret at a glance than raw JSON/API output.
