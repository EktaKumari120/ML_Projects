# Movie Industry Analysis

## Business Problem
Understand what drives financial success in the film industry — analyzing 
the relationship between budget, revenue, and audience ratings across genres.

## Approach
- Stored and queried movie data using SQLite
- Calculated ROI (%) per movie and budget-to-revenue correlations using Pandas
- Analyzed IMDb rating distributions by genre
- Visualized findings with Matplotlib

## Tools & Libraries
Python, SQLite, Pandas, Matplotlib

## Key Insight
Higher budgets don't guarantee higher ROI — several genres showed strong 
returns on comparatively low budgets, while some high-budget films 
underperformed relative to their cost.
